## 핵심 결론

1. **PTV Vissim은 상용 소프트웨어**입니다. 패키지(규모)에 따라 가격이 달라지며
   별도 견적을 받아야 합니다. 무료로 쓸 수 있는 경로는
   **학생(1년 무료)·체험판(30일)·데모 라이선스(모델 열람용)** 뿐입니다.
2. **Vissim 수준의 미시적 다중 모드 시뮬레이션을 무료로 쓰고 싶다면 Eclipse SUMO**가
   사실상 표준 오픈소스 대안입니다 (EPL 2.0/GPL 라이선스, 전 세계 연구·산업에서 사용).
3. SUMO는 Windows에서 설치형 패키지로 바로 사용 가능하며, GUI(netedit·sumo-gui),
   OpenStreetMap 연동, 보행자/대중교통/자전거/철도/배출가스 모델, Python(TraCI) 자동화를
   모두 지원합니다.
